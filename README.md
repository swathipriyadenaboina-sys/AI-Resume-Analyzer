# AI Resume Analyzer

An AI-powered Resume Analyzer built using Python and Streamlit.

## Features

* Resume PDF Upload
* Resume Text Extraction
* Skill Detection
* ATS Score Calculation
* Job Description Matching
* NLP-based Cosine Similarity
* Resume Suggestions

## Technologies Used

* Python
* Streamlit
* Scikit-learn
* pdfplumber
* NLP
* Machine Learning

## How It Works

The system extracts resume text from PDF files and compares it with job descriptions using TF-IDF Vectorization and Cosine Similarity.
